# Salah Now

A calm, private companion for your five daily prayers.

## Features

- Accurate prayer times, worked out on the phone
- Home-screen widget with a live countdown
- Qibla direction
- Gentle reminders, and a daily Quran reminder
- The complete Quran in Arabic
- Quiet prayer tracker
- Light and dark themes, English and Arabic
- No account
- No cloud
- No ads
- No tracking
